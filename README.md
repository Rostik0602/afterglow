# Afterglow

Прототип вітрини AI-блогерів, тестове завдання. Чотири віртуальні персонажі, профіль з демо-чатом і перехід у Telegram. Верстка mobile-first.

Демо: https://afterglow-theta-eight.vercel.app

![Afterglow](https://afterglow-theta-eight.vercel.app/opengraph-image)

## Ідея

Хотів, щоб це виглядало як продукт, з персонажами якого можна поговорити, а не як сторінка з чотирма картинками. Тому головна механіка тут демо-чат. Персонаж друкує, відповідає на вибрані питання, а після пари реплік пропонує продовжити розмову в Telegram. Так перехід у Telegram стає логічним кроком після чату.

## Що є на сторінці

- Каталог з 4 персонажів: двоє чоловіків і дві жінки, ніші технології, мода, подорожі й лайфстайл. На телефоні картки гортаються свайпом, на планшеті сітка 2 на 2, на десктопі 4 в ряд.
- Фільтр за тематикою з анімацією. Список тем збирається з даних.
- Профіль персонажа. На телефоні відкривається шторкою знизу, яку можна змахнути вниз, на десктопі модальним вікном. Також закривається хрестиком, кліком по фону, Esc і кнопкою «Назад».
- Демо-чат з індикатором набору, швидкими відповідями і кнопкою переходу в Telegram.
- Вкладка з постами, лайк можна поставити.
- У кожного персонажа свій неоновий колір, взятий зі світла на його фото. Він використовується в картці, профілі й чаті.
- OG-картинка генерується кодом, тому посилання нормально виглядає в Telegram і соцмережах.

## Рішення

- Відкритий профіль зберігається в URL (`?blogger=mark`). Можна скинути посилання на конкретного персонажа, а кнопка «Назад» на телефоні закриває профіль і не викидає з сайту.
- Посилання в Telegram мають параметр start, наприклад `t.me/bot?start=mark__tiktok`. Справжній бот міг би за ним зрозуміти, до якого персонажа і з якого джерела прийшла людина. Джерело береться з `?src=` або `?utm_source=`, тож одну сторінку можна ставити під різний трафік.
- Тексти лежать окремо від верстки: загальні в `src/data/site.ts`, персонажі з діалогами й постами в `src/data/bloggers.ts`. Щоб додати персонажа, достатньо дописати об'єкт у масив.
- Кнопок Telegram чотири: у шапці, у hero, в чаті і у фінальному блоці. Була ще плаваюча кнопка знизу, але я її прибрав, бо Telegram ставало забагато.
- Неонові плями на фоні зроблені радіальними градієнтами, а не через `filter: blur`, щоб не гальмувало на слабких телефонах. Більшість секцій це серверні компоненти.
- Redux і RTK Query не підключав. Глобального стану тут майже немає, API за ТЗ не потрібен. Якщо з'явиться бекенд, дані можна буде перенести на RTK Query без переписування компонентів.
- Доступність: семантична розмітка, видимий фокус з клавіатури, ARIA для вкладок і діалогу, урахування `prefers-reduced-motion`.

## Стек

Next.js (App Router), React, TypeScript, Tailwind CSS v4, Motion, Radix UI, Lucide. Деплой на Vercel.

## AI-інструменти

Портрети згенеровані в Leonardo.ai (модель Lucid Realism). Колір неонового світла на кожному фото потім ліг в основу кольорів сайту.

Код писав разом з Claude: архітектура, генерація і перевірка коду, тексти.

## Структура

```
src/
├── app/            # layout, сторінка, стилі, favicon, OG-картинка
├── components/
│   ├── blogger/    # картка, профіль, чат, пости, фільтр
│   ├── layout/     # шапка, футер
│   ├── sections/   # hero, каталог, «Як це працює», фінальний блок
│   ├── ui/         # кнопка, чипси, контейнер, анімації
│   └── icons/
├── data/           # контент сайту й персонажів
├── hooks/          # профіль в URL, джерело трафіку, логіка чату
├── lib/            # посилання в Telegram, форматування, утиліти
└── types/
```

## Запуск

```bash
git clone https://github.com/Rostik0602/afterglow.git
cd afterglow
npm install
npm run dev
```

Далі відкрити http://localhost:3000.

Для перевірки:

- [/?blogger=milana](https://afterglow-theta-eight.vercel.app/?blogger=milana) одразу відкриває профіль Мілани;
- [/?src=tiktok](https://afterglow-theta-eight.vercel.app/?src=tiktok) додає мітку джерела до посилань у Telegram.

## Що можна зробити далі

- Підключити справжнього Telegram-бота й обробляти параметр start.
- Замінити скриптований чат на відповіді LLM з характером персонажа.
- Перенести дані на API і RTK Query, додати CMS для персонажів.
- Додати аналітику: перегляди профілів, проходження чату, переходи в Telegram.
- Тестувати різні заголовки й кнопки під різні джерела трафіку.
